# Design and Development of Deep Learning Assisted Intelligent Automated Areca Sorting System

This project focuses on the design and development of an intelligent automated system for classifying and sorting arecanuts based on their maturity using deep learning and computer vision.

A deep learning model based on VGG16 transfer learning is used to classify ripe and unripe arecanuts from camera images. The system integrates ROS for communication between the vision and sorting modules, while a Raspberry Pi and ESP32 control the image acquisition and servo-based sorting mechanism.

## Key Features

* Automated ripe and unripe arecanut classification
* Deep learning-based image classification
* Computer vision and image processing
* ROS-based communication between system modules
* Raspberry Pi-based system integration
* ESP32-based servo motor control
* Automated physical sorting mechanism
